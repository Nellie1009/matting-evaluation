# 抠图能力评测 Skill

面向 Excel 中图片模型生成结果的人物抠图评测技能，适用于只有参考图、模型和生成结果、尚无评分列或数据分析 sheet 的原始导出表。

## 功能

- 补齐评分表头和任务标识，按参考图逐条评估生成图。
- 检查真实 alpha 透明，区分纯色背景和烘焙棋盘格。
- 六维评分：透明背景、主体识别、抠图精细度、色彩还原、避免 AI 修改、避免形变/裁切，满分 24。
- 主体边缘明显毛边/杂色归精细度 2 分，轻微杂色归 3 分；完整标准见 [rubric.md](references/rubric.md)。
- 生成任务对比、厂商分组、模型六维明细、维度分析及难度分类统计，汇总尽量用公式引用源评分。
- 用条件格式动态标记最高分绿底、最低分红底，处理并列、同分、缺失和重复运行。

视觉评分由调用技能的模型逐图对照判断；附带的脚本只生成公式计划，不是独立运行的图像评分模型，也不会直接修改 Excel。

## 使用

将本仓库的技能内容放入个人技能目录 `~/.codex/skills/matting-evaluation/`，保留目录结构。调用示例：

> 使用 $matting-evaluation 按我的抠图标准评估这份 Excel，补全评分列和数据分析 sheet，并用公式联动汇总与极值底色。

执行 Excel 编辑时，按技能入口要求使用当前环境的 spreadsheets 技能和表格运行库。用户当次给出的新标准优先于仓库默认标准。

## 公式计划工具

```bash
python scripts/analysis_plan.py mapping.json --out plan.json
```

映射文件格式见 [数据分析说明](references/analysis.md)。工具按实际任务、模型及源列生成单元格公式和条件格式比较计划；Excel 写入、模板位置适配和厂商分组由调用方完成。

总分和分析结果依赖源评分。缺失结果保留为空，不当作零分；重复运行先在同任务同系列内平均，再按任务等权汇总。默认只有覆盖全部任务的系列参与综合排名，分类比较按对应类别覆盖情况判断资格。

仓库包含技能文档与公式工具，不包含原始 Excel、参考图或模型生成结果。
